Deliver automatic backup on application close (DATA-03). When the user exits the application, the system automatically creates a timestamped backup to %LocalAppData%\FileTracker\autobackups\.     - BEFORE `await _host.StopAsync(...)`, add the auto-backup call:
      ```csharp
      protected override async void OnExit(ExitEventArgs e)
      {
          if (_host is not null)
          {
              // D-06: Auto-backup on close before host shutdown
              try
              {
                  var backupService = _host.Services.GetRequiredService<IBackupService>();
                  await backupService.PerformAutoBackupIfEnabledAsync();
              }
              catch (Exception ex)
              {
                  // Auto-backup failure should not prevent app exit
                  Log.Logger.Warning(ex, "Auto-backup on exit failed");
              }

              await _host.StopAsync(TimeSpan.FromSeconds(5));
              _host.Dispose();
          }
          Log.CloseAndFlush();
          base.OnExit(e);
      }
      ```
    - Key points:
      - Auto-backup runs BEFORE `StopAsync` because the SqliteConnection must still be open for `BackupDatabase()` to work
      - Wrapped in try/catch so backup failure doesn't block app shutdown
      - Failure logged as Warning, not Error — app is exiting anyway
      - Per D-06: auto-backup goes to `%LocalAppData%\FileTracker\autobackups\` (handled inside PerformAutoBackupIfEnabledAsync)
    - Per D-07: rolling cleanup keeps last 7 (handled inside BackupService)
    - Per D-08: enabled by default via appsettings.json `Backup:AutoBackupEnabled: true`

### Key RESEARCH.md patterns for this plan

**Pattern 1 (§Dynamic Parameterized Search):** 
- Build SQL WHERE clause dynamically using `DynamicParameters` and `List<string> conditions`
- Only non-empty filters add WHERE conditions — all combined with AND
- LIKE with leading/trailing `%` for partial matching (`$"%{value}%"`)
- Date range uses `>= @FromDate` and `<= @ToDate` with `yyyy-MM-dd` format
- SenderOrRecipient checks BOTH columns: `(d.Sender LIKE @SenderOrRec OR d.Recipient LIKE @SenderOrRec)`
- Base WHERE always includes `d.IsDeleted = 0`
- Two queries: one for paginated results (LIMIT/OFFSET), one for COUNT(*)

**Pattern 4 (§Pagination State in ViewModel):**
- SearchViewModel tracks `CurrentPage`, `PageSize` (20), `TotalCount`
- Computed `TotalPages`, `HasPreviousPage`, `HasNextPage`
- Search command resets to page 1, Prev/Next commands increment/decrement
- Cap PageSize at 100 in ViewModel for DoS prevention

**D-03:** Search triggered by Search button click — NOT live filtering on keystroke

**D-02:** Results in existing DataGrid with SQL LIMIT/OFFSET pagination

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

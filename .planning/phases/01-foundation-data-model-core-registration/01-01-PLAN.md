<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Form input → ViewModel | Untrusted user text enters via WPF bindings |
| ViewModel → DocumentService | DTO passes from UI layer to business logic |
| DocumentService → SQLite | Parameterized SQL crosses into database |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | RegisterDocumentViewModel.SubmitAsync | mitigate | Validate all required fields before calling service — `string.IsNullOrWhiteSpace` checks on Subject and OriginalFileNumber |
| T-01-02 | Tampering | DocumentRepository.InsertAsync | mitigate | Dapper parameterized queries (`new { Subject, OriginalFileNumber, ... }`) — never string concatenation for SQL |
| T-01-03 | Tampering | OriginalFileNumber field | mitigate | UNIQUE constraint on Documents.OriginalFileNumber column — SQLite rejects duplicates at DB level |
| T-01-04 | Denial of Service | Remarks TextBox | accept | No length limit enforced at UI — accept risk. SQLite handles large text. 200-document limit on GetAllAsync prevents list bloat |
| T-01-05 | Information Disclosure | SQLite database file | accept | File at `%LocalAppData%\FileTracker\` is user-specific. No multi-user access. No network exposure |
| T-01-SC | Tampering | NuGet package installs | mitigate | All packages verified against nuget.org per RESEARCH.md §Package Legitimacy Audit. No [SLOP] packages. FluentAssertions pinned to v7.2.2 (Apache-2.0) to avoid v8 licensing issue |
</threat_model>
